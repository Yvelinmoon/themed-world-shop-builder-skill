Create one original shop assistant character who strongly fits the current shop idea, shop name, assistant role, and assistant summary.

- Do not copy official characters, copyrighted mascots, franchise logos, game UI, or recognizable protected designs.
- Do not borrow roles, costumes, props, species, body features, age, gender, setting, or genre details from any previous shop or example.

- Clothing, accessories, color palette, hairstyle/body silhouette, and expression style must come from the current shop concept only.
- No text, no name tags, no letters, no numbers, no labels, no logos.

STRICT SHEET FORMAT:
- one horizontal 16:9 image
- pure white background only
- exactly four separate half-body portraits arranged as a strict 2x2 grid

- half-body portrait framing only; head, shoulders, outfit, hands, and accessories if visible must stay inside each quadrant

- leave generous white padding around hair/head, shoulders, hands, accessories, and outfit
- no border, no grid line, no labels, no typography, no speech bubbles, no props crossing quadrants

STYLE:
- polished casual game portrait sheet with clean readable silhouette
- warm handcrafted illustrated asset quality unless the current shop concept clearly requests another style
- consistent lighting, scale, and character identity across all four portraits
